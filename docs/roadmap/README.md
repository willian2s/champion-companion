# Roadmap do Champion Companion

Esta pasta contém a direção macro do produto e o histórico das fases.

## Fonte autoritativa

- `champion-companion-roadmap.md` preserva o roadmap histórico completo e o estado das fases já executadas.
- `post-phase-15-direction.md` é a direção autoritativa para o trabalho posterior à Fase 15.

Quando houver divergência entre as seções futuras antigas de `champion-companion-roadmap.md` e `post-phase-15-direction.md`, prevalece `post-phase-15-direction.md`.

## Fases e tickers

Número de fase e ticker de spec/task são conceitos independentes.

Exemplos:

- a Fase 014 usou ticker `014` por coincidência;
- a Spec/Task `021` foi uma correção posterior de D4/calendário e **não representa a Fase 21**;
- novos trabalhos corretivos podem receber qualquer ticker disponível sem alterar a sequência das fases.

As fases representam evolução macro do produto. Specs/tasks representam unidades de trabalho executáveis.

Não reutilizar números de fases removidas para novos trabalhos. Quando uma fase deixar de fazer sentido, registrar sua remoção no roadmap sem renumerar o histórico.
